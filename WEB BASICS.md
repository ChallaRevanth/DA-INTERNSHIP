WEB APPLICATION:
---------------
            ->any application that will be run in browsers is called as web application.
            ->types:
                1.Static web application:
                    ->Any web application doesn't have functionalities.
                    ->to build static web application we used only HTML and CSS.

                2.Dynamic web application:
                    ->Any web application have functionalities.
                    ->to build dynamic web application we use HTML and CSS and Javascript.


    Web pages:-
    ----------
            ->HTML documents is called as a web pages.

    Web site:-
    ---------
            ->collection of web pages is called as web site.

    Web server:-
    -----------
            ->collection of websites is known as a web server.
            ->web server will understand only IP address.
            



HTML:-
------
     ->HTML stands for Hyper text markup language used to build structure of web pages.
     ->introduced in 1991 and previously SGML language is used.
     ->present version of HTML is HTML5.
     ->HTML contains series of elements.

Tags:-
------
    ->tags are the predefined words which are enclosed with both opening and closing angular brackets.
    ex:<html>,<body>,<title>,...

    Types:
        1.Paired tags:
            ->any tags having both opening and closing tags.
            ex:<html></html>, <body></body>, <title></title>, <div></div>, <p></p>,
