Functions in python:-
--------------------
            ->functions are the block of statements that will gets executed whenever it is called.
            ->in python,we define functions using 'def' keyword.

            Why we need function:
            ---------------------
                        ->to perform code reusability.
                        ->to perform specific task.
                        ->to reduce boiler plate.
                        ->to improve code readability.
                        ->Syntax:
                           def functionName(parameters…):
                               Statements
            ex:
                details=[]
                #function with parameter and without return values.
                def storeDetails(empName,empAge,empRole):
                    details.append({'name':empName,'age':empAge,'role':empRole})

                #function without parameter and return values.
                def displayDetails():
                    print(details)

                storeDetails('suhas',20,'hacker')
                storeDetails('manith',20,'developer')
                displayDetails()
            Types of functions:-
            --------------------
            1.user defined functions:-
                        ->any functions which is declared by user or programmer as per their requirement.
                        ->ex:
                            def factorial(num):
                              fact=1
                              for val in range(1,num+1):
                                fact*=val
                              return fact
                            print(factorial(5))
                            print(factorial(7))
                            print(factorial(9))
 
            2.predefined function:-
                    ->they are the in build functions already present in python.
                    ->ex:print(),max(),min(),count(),len(),pow(),abs()...,etc

OOP's(object oriented programming):-
------
      1.class:
      ->it is a template or blueprint used for creating objects.
      ->it contains 
            -variables (attributes/data members)
            -function (functional members/methods)
            -constructors
      ->syntax:
            class className:
                    Functions

      2.object:
            ->it is a realtime entity which have both state(variable) and behaviour(function).
            ->object is an instance which have both attributes and behaviour.
            ->state means what it can hold.
            ->behaviour means how it can behave.
            ->syntax:
                    class className:
                            pass

                            className  ->object
      3.constructors:
            ->it is a special method used to initialize variable values.
            ->it will get invoked whenever we create object for the class.
            ->in python,we can declare constructor using '__init__()' function.

OOP's Principles:-
-----------------
            1.Inheritance.
            2.Abstraction.
            3.Encapsulation.
            4.Polymorphism.
NOTE:->to perform code reusability,we need inheritance.
     ->to achieve abstraction we require inheritance.
     ->to achieve method overriding,inheritance is required.
    1.Inheritance:
            ->Acquiring/inheriting the properties from one class to another class.
            ->Types of inheritance:
                    -Single level inheritance:A child class inherits from exactly one parent class.
                    -Multi level inheritance:A child class inherits from a parent class, which itself inherits from another parent class. This forms a linear, multi-tiered chain of inheritance (like grandchild → parent → grandparent).
                    -Hybrid inheritance:A complex architecture combining two or more of the inheritance types listed above. Python manages potential conflicts or lookup ordering in these networks using the Method Resolution Order (MRO) algorithm.
                    -Hierarchial inheritance:Multiple child classes inherit from a single, shared parent class. It is the structural opposite of multiple inheritance.
                    -Multiple inheritance:A child class inherits directly from two or more parent classes.

                1.Single level inheritance:
                    ->single sub class/single child class/single derived class acquiring properties from only one parent class/super class/base class.
                2.Multi level inheritance:
                    ->subclass acquiring properties from its superClass inturn superClass acquiring from its superClass.
                3.Hierarchial inheritance:
                    ->multiple subclasses inherit properties from only one superclass.
                4.Hybrid inheritance:
                    ->combination of single level or multi level or hierarchial level. 
                5.Multiple inheritance:
                    ->single subclass is inheriting/acquiring properties from multiple super classes.

    2.Polymorphism:
            ->same method showing different behaviour throughout its life cycle.
            ->in python,to do Polymorphism we require inheritance and method overriding.
            ->method overriding:
                    -developing same method in subclass as in superclass but different implementations in subclass.
                    -we use this,whenever we want to add new features to existing system.
                    -in case of method overriding, we will get over readed implementations.
            ->method hiding:
                    -subclass implementations hide the properties of superclass.
            ->super()


    3.Encapsulation:
            ->wrapping up of a data members(variables) and function members(functions) into a single point by declaring private variable.
            ->access specifiers:
                    1.public            ex:name
                    2.protected         ex:_name
                    3.private           ex:__name

    4.Abstraction:
            ->hiding complexity of the system and exposing functions required to the end user.
            ->we can achieve abstraction using inheritance and abstract class.
